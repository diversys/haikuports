About this repository

This is a personal repository by Diver. It is not endorsed by Haiku or HaikuPorts. Everything here is provided AS-IS, without warranties of any kind. Review package-manager proposals before installing or updating.

Install

Open Terminal on Haiku R1/beta6 x86_64 and run these commands.

1. Add the repository

pkgman add-repo https://diversys.github.io/haikuports/r1beta6/x86_64
pkgman refresh DiverHaikuPackages

2. Install a package

pkgman install testapp

Replace testapp with the package you need. The official Haiku and HaikuPorts repositories stay enabled and provide the rest.

Updates

pkgman add-repo saves the repository across restarts, and SoftwareUpdater uses it for future updates. Update from Terminal any time: 

pkgman refresh DiverHaikuPackages
pkgman update

You can also add it in Deskbar → Preferences → Repositories with the + button. Keep Haiku, HaikuPorts, and DiverHaikuPackages enabled. To stop using it: pkgman drop-repo DiverHaikuPackages.
